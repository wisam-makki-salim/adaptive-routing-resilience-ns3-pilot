# Supervisor Facing Summary

I developed a reproducible ns-3 pilot to test whether lightweight OLSR timer adaptation can preserve service continuity under gradual link degradation and node failure. The study used three controlled scenarios, two UDP flows, 20 paired seeds per comparison, and explicit measures of delivery, delay, throughput, control overhead, recovery, and route stability. The original adaptive mechanism did not produce a stable resilience benefit: service-effect intervals crossed zero, while control overhead increased whenever adaptation triggered. A component ablation isolated aggressive HELLO acceleration as the source of an adverse cross-flow tail event, whereas detection without timer modification reproduced the baseline exactly. A lower failure threshold showed exploratory improvement but is not presented as confirmed because it still requires evaluation on fresh seeds and another topology. This pilot extends my MSc work on DDoS mitigation in inter-vehicle networks using NS-2, AODV, and OLSR, and provides an executable starting point for doctoral research on guarded adaptation, multi-topology validation, and resilient network control.
